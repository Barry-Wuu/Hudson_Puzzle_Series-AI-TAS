### 入門 001 特例（无归档视频）

早期录播从 002 起，001 没有归档视频。`l001_clear.png` 取自实机重打（在 310 关全通存档下
重进第 1 問），`クリアタイム 00:00:33`、**4★ 全亮**、総得点 1520，源图 `intro001_source.png`
一并归档。

抓帧要点：结算页星星是**逐颗点亮**的动画，连续抓帧实测帧分布
`{0:37, 1:4, 2:6, 3:4, 4:1}`，必须等第 4 颗亮起再取。上一轮手动解锁时留的
`ny_after_fill.png`（用时 00:01:07）只有 3 颗暗星，是抓在动画中途，未采用。

否则答案盘填不满、不判 CLEAR。

## 图像规格：BGR555 16 位量化

全部 **315 张** PNG 已做 BGR555（每通道 5 bit）量化，`quant16.py` 幂等可重跑：

```bash
cd validation && python3 quant16.py .
# 315 张：41.65 MB → 20.03 MB（−51.9%），色数中位 14173 → 1856
```

为什么不用 Vol.11/12/13 的 128 色索引：那几卷是**原生 256×384 截图**（≤150 色），
调色板量化近乎恒等；本卷 309 张图源是 **h264 视频帧**（每张 1.4~1.7 万色，含压缩噪声），
压到 128 色会把金星橙色压出色域、判星大面积失效（Vol.10 README 实测 300 张里 115 张读错）。
故按 Vol.10 口径只做 `(v>>3)<<3|4` 的 5 bit/通道量化，既还原 DS 真实发色又去掉插值噪声。
写入采用「临时文件 + `os.replace`」原子替换，避免中途中断留下 0 字节图。

## 判星方法（Vol.4 专用，`check_stars.py`）

- 星星行带 **y=322..348**（Vol.10 是 292..328，本卷结算页布局不同）
- 暖色掩码 `(R>150)&(R>B+60)&(G>B+25)&(G>90)`；得点旁的大金星在 y≈365，不在行带内
- 列投影切段 → 合并间隙 ≤4px（抗锯齿会把一颗星拆成两段）→ 只保留宽 8~20px 段 → 段数即星数
- 实测：入門 / やさしい 4 段、ふつう 5 段（x≈98 起，间距≈16）、むずかしい 6 段（x≈92 起）

复核（量化前后结果逐张一致）：

```bash
cd validation && python3 check_stars.py
# mode1_tutorial: 20 张 满星4★ {4: 20}
# mode2_easy:     90 张 满星4★ {4: 90}
# mode3_medium:  120 张 满星5★ {5: 120}
# mode4_hard:     80 张 满星6★ {6: 80}
# 结论: 全部满星且齐号
```
