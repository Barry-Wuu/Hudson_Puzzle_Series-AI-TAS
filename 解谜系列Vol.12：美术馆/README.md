# 《解谜系列Vol.12：美術館 / AKARI（点灯）》AI-TAS 战线

> Hudson「解谜系列」第 12 作。NDS 日版，ROM 名 `vol12.nds`，存档 `vol12.dsv`（按 ROM 名由 DeSmuME 落盘于 `~/.config/desmume/vol12.dsv`）。
> 玩法：Akari（点灯）逻辑谜题，在黑墙上放置灯泡，使每个白格能被照亮且灯泡互不直射。

## 四模式与规模

| 模式 | 题量 | 盘面 | 满星上限 |
|---|---|---|---|
| 入門（tutorial） | 20 | 6×6 | 3 |
| やさしい（easy） | 100 | 10×10（1–80）/ 18×10（81–100 大盘） | 4 |
| ふつう（medium） | 110 | 10×10 – 24×14（递增） | 5 |
| むずかしい（hard） | 70 | 24×14（×50）+ 36×20（×20） | 6 |

> 合计 300 关（20+100+110+70），与游戏「全4章300关」一致；满星合计 20×3 + 100×4 + 110×5 + 70×6 = **1430 星**。

## 取证约定（validation/）

每关一张 `lNNN_clear.png` = 上屏已解盘面 + 下屏クリアタイム + 星级。
- **图片规格**：256×384（DS 双屏原生），8-bit 索引色 PNG（128 色自适应调色板），单张约 33 KB，300 张合计 9.7 MB —— 与 Vol.11 取证图同规格。B 站源为 480×720（1.875× 放大），已缩回原生。
- 本地录像：下屏蓝面板密度定位通关页 → 取星级定格的「稳定尾帧」。
- B 站录像：布局不同，改用「右侧菜单消失 + 上屏填满盘面 + 下屏含金星」定位，取组内下屏最亮帧；相邻 <3s 组判为同关合并。
详见 `validation/README.md`。
