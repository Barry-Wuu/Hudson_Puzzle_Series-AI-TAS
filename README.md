# Hudson_Puzzle_Series-AI-TAS

> **向 Hudson「解谜系列」全线宣战的 AI-TAS 战线。**
> 兵符：模拟器 + 像素判定 + 动作序列规划 + 逐关实机取证。

## 宣战书

Hudson 的解谜系列，曾是掌机上挡住无数人的一排墙。今天，我们向这条产品线正式宣战——不赌运气、不背板，以 **AI 规划求解**、**像素级状态判定**、**逐关实机取证**，把每一作从标题画面一路打到制作组名单。

三条军规，字字为凭：

1. **一切数字来自真实日志**——关卡数、耗时、规模全部实测实记，拒绝编造；
2. **一切结论以实机截图为准**——选关页蓝底即通关，正解横幅即胜利，存档即铁证；
3. **一切踩坑写进战报**——已失败的路径同样入库，后来者不必重蹈覆辙。

## 战场档案

各作结构一致，以下以 **[`解谜系列Vol.13：汉字解谜/`](解谜系列Vol.13：汉字解谜/)** 为例：

| 文件 / 目录 | 内容 |
|---|---|
| `README.md` | 详细项目文档：三种模式解析、规划/执行管线、数据层规格 |
| `PITFALLS.md` | 踩坑清单（接手必读，避开所有「已失败、勿重试」方案） |
| `REPORT.md` | 项目总报告 |
| `ai-tas/` | 求解 / 规划 / 录制全管线脚本（`run.py` 一键复现） |
| `validation/` | 逐关通关证据截图 + `plans.json` 统一动作序列仓库 |
| `music_extract/` | 盘内 BGM 提取与渲染（SSEQ → MIDI → WAV） |
| `saves/` | 实机存档 |
