## 游戏与难度

- ROM：`/workspace/roms/解谜系列Vol.08：假名字谜3.nds`，8,388,608 B，md5 4ef3094d…
- 主菜单：中断データ / 通常問題 / 設定問題 / バラエティ問題。
- 「通常問題」3 档：やさしい(090, 全 10×10) / ふつう / むずかしい。
- 题库 CPQ. 块有 6 个难度字段（0~5，共 299 关有效 +1 哨兵），通常問題只暴露前 3 档。

## 玩法与答案

- 每格是 1~16 的数字，每个数字**全局固定**对应一个假名；横向/纵向连续格（黑格
  `0x7f` 分隔）组成日语词条。给 16 个数字各指定假名，全部词条成词即通关。
- 数据源：NitroFS `file_04.bin` → `CPQ.` 块 @ `0x4fcb8`，301 条记录。
  每条记录 `header(0x1c) + grid(w×h) + tail(16B=数字1~16→假名表索引)`。
- 假名表 71 音（清音46+浊音25）；索引71 = **长音「ー」**（ROM 实测 0x815b；旧版误推定为促音「っ」，已纠错）。
- 提取器：`ai-tas/extract_vol8_answers.py` → `answers.json`。

## 最快打法

**跳过推理，直接查表填**：映射全局，每关只需为盘面出现的数字各指定一次假名。

- 填字机制（第三轮最终确认，见标定报告第七节）：**点数字格选中该数字 → 点对应假名键 2 次填入**。
  连续点不同假名会互相覆盖，必须逐数字"选格+填"；盘面格坐标 `(24+26c,19+26r)`。
  旧版"直接点假名键全局替换、无需选格"的说法过于简化，已纠正。
- 键位公式 `x=15+16*col, y=119+16*row`，15 列×5 行五十音图，第9列 ン/ー，
  第10列起浊音，第14列半浊音。详见 `标定报告_第一个难度最快打法.md` 第六节。
- 每关操作数 ≈ 命中数字种类数 K × 2 次点击 + 1 次チェック。

## 环境备忘

- Xvfb `:99` + `desmume-cli`（窗口须 move 到 (384,192)）；ROM 无存档依赖教程。
- **按键必须用 XTEST**（`xdotool key <key>`，不带 `--window`）：SDL 忽略 XSendEvent，
  `ds.press` 的 `--window` 写法对按键无效（对触摸无效的说法不适用——触摸用坐标有效）。
  键位：A=X B=Z R=E L=Q Start=Return Select=BackSpace 方向=WASD；Escape 退出模拟器。
- 教程示例盘面格距 24px（中心=(28+24col,19+24row)），真实关卡键盘/盘面另见标定报告。
