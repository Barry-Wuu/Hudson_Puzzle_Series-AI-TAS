## 提取方法
- **本地段（むずかしい、やさしい 081–100）**：下屏 y235–365 蓝色面板密度 > 0.08 定位「通关面板」；
  取通关窗末组的「稳定尾帧」（星级已定格、未切选关），避开星级逐颗弹出动画与里程碑横幅遮挡段。
- **B 站段（入門、やさしい 001–080、ふつう）**：B 站录屏布局不同（无实心蓝面板，而是深蓝结算框 + 金星行 + 右侧菜单消失），
  故改用「下屏右侧菜单条消失 + 下屏非黑 + 上屏为填满盘面 + 下屏含金星」定位结算屏，取组内下屏最亮帧；
  相邻结算组间隔 <3s 者（同一关被短暂非结算帧切成两段）合并。编号按录像出现顺序顺排。
- **编号核验**：已抽帧核对 入門 l001=001 / l020=020、やさしい l001=001 / l040=040 / l080=080、
  ふつう l001=001 / l028=028 / l110=110，均无漂移。
