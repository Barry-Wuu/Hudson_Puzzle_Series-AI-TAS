| # | 模式 | 难度 / 规模 | 填字机制 | 进度 |

> 左上のマス目から中心に向かって**時計回り**に熟語をうめていきます。
> **渦巻き状**のガイドラインに沿って、熟語が並んでいるので、ガイドラインをまたぐことはありません。

拆成三条：

1. **螺旋** —— 从**左上角**出发、**顺时针**、沿一条**渦巻き状（螺旋）引导线**一圈圈**向中心**填词，词条不跨引导线；
2. **接龙** —— 沿线的词条是**熟语**，且**首尾相接**（前一语的末字＝后一语的首字，共用同一个格子。
   官方示例：`生徒会長` → `長生`）；
3. **同字同号** —— 同一个汉字在盘面多处出现时标**同一个编号**，所以推理出一个编号就**一次填满它的全部格子**
   （这是与模式1「逐格绑定」最大的差别，也是模式2 输入次数 = 编号数而非格子数的原因）。

> （与"顺时针螺旋"在左边界的行进方向吻合；按普通的"逐行横读"是读不通的。）

本作收录 300 题、分三个变体（**Kanji Crossword / Idiom Crossword / White Puzzle**），模式2 属于 **Idiom Crossword（熟语填字）**。

  ② 记录内**相对定位**：`条目区`（cnt × 汉字+坐标对+`FF FF`）→ **行列字段 2B**（直接读出盘面尺寸）→
  **解盘** `2×R×C` 字节（整盘正解，SJIS 行主序）→ 跳过 2B → **槽位区** `R×C` 字节（`byte & 0x7F` = 数字组号，0 = 已给）→
  候选表（1B 字数 + 2×N 汉字 + `CC` 终止）；
  ③ **硬口径：槽位区非零字节数 = 游戏内「口の数」**（选关页上屏可读）⇒ 可在全库**唯一**定位一关。
  另两个判据：`行列字段` 给盘面尺寸；**满矩形**（模式2 每格都有内容）vs **非满矩形**（模式1 有黑格）可粗分模式。

  > ⚠️ **口径例外**：認定問題 / 通常問題这类**带黑格**的盘，游戏内「ロの数」= **徽章格总数**
  > （`sum(len(v) for v in solve2.solve(i)['badge_cells'].values())`），**不是**槽位区非零字节数（后者只对 8×8 满盘成立，见 §S30.8）。

  > 须看盘面定案，工具 `ai-tas/scripts/identify_kentei_board.py`，见 §S51）。

## 快速上手

见 `PITFALLS.md` 末章「快速上手」。最小命令序列：

```bash
bash 解谜系列Vol.13：汉字解谜/ai-tas/scripts/ensure_env.sh                    # 起 Xvfb + 模拟器（幂等；本沙箱 DISPLAY=:0）
cd 解谜系列Vol.13：汉字解谜/ai-tas/scripts

# 单关：冷启动 → 导航 → 填字 → 结算（模式 1/2/3 同一个入口）
python3 run.py --mode 1 --diff yasashii --level 3

# 批量：冷启动一次、逐关续打
python3 run.py --mode 2 --diff futsuu --from 1 --to 15

# 认定問題（ブロンズ/シルバー/ゴールド/プラチナ 四级）
python3 run.py --mode 1 --kentei bronze

# 纯计算（不碰模拟器）：看某关的规划串统计
python3 run.py --mode 1 --diff yasashii --level 3 --dry-run
```

> 环境：本沙箱用 `DISPLAY=:0`（`ensure_env.sh` 默认 `:99`，用 `AI_TAS_DISPLAY=:0` 覆盖）。
> 证据图默认落 `validation/mode<模式号>_<序>_<难度>/`，用 `--shot-dir` 覆盖。
