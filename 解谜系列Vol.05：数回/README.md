## 数据结构（实测，非推测）

ROM `NitroFS` 5 个 FAT 项；题库打包在 `indata/add01dat.bin`（3,868,148 B）。
该文件是通用 pack：开头 u32 偏移表（**1704 项**），其后 1704 条记录
（图形 RSC/RGI/SCR/IMG、题库、素材混排）。

**题库区 = pack 偏移表 idx 1395..1703，共 308 条定长记录**：

| 尺寸(宽×高) | 条数 | 记录字节 | 备注 |
|---|---|---|---|
| 6×6 | 24 | 100 | 入門教学档 |
| 10×10 | 101 | 228 | 含 1 条尺寸样本头 idx1396 |
| 18×10 | 81 | 388 | 含 1 条尺寸样本头 idx1397 |
| 24×14 | 61 | 700 | 含 1 条尺寸样本头 idx1398 |
| 36×20 | 41 | 1468 | 含 1 条尺寸样本头 idx1399 |

> 后 4 档尺寸与 Vol.12 美术馆通用网格 `(10,10)/(18,10)/(24,14)/(36,20)` 完全一致。

每条记录布局（308/308 自检一致）：
```
[0] u8 w   [1] u8 h   [2] u8 标记A(0..4)   [3] u8 标记B(0..4)
[4 : 4+w*h]              题目数字盘，逐行 u8；0/1/2/3=线索，4=空格
[4+w*h : ...]            0/1 段（连续到首个 >1 字节）；301 题长 w*h-2，7 题 w*h-1
                         ★ 语义未明，非答案，勿当作官方环路使用
[之后]                    图形元数据：多数以 C4 96 49 01 开头（后 2 字节为变化指针），
                         少数 24×14 题为 E1 00 00 A8 93 00 00 80
```

自检口径见 `extract_vol5_answers.py`：① 偏移表首尾相接覆盖文件末尾；
② 尺寸/记录长度白名单；③ 数字盘值域 ⊆{0..4}；④ 0/1 段严格 0/1 且长度 ∈{w*h-2, w*h-1}；
⑤ 段后仍有图形数据。

## 实机环境（本轮已打通，可续用）

```bash
# 显示 / 音频
Xvfb :99 -screen 0 1024x768x24 -nolisten tcp &
XDG_RUNTIME_DIR=/tmp/xdg-pulse pulseaudio --start --exit-idle-time=-1 --daemonize=yes
# 启动（必须带 --cpu-mode=1 --num-cores=1，否则触屏点击不生效）
DISPLAY=:99 XDG_RUNTIME_DIR=/tmp/xdg-pulse SDL_AUDIODRIVER=pulse SDL_VIDEODRIVER=x11 \
  SDL_VIDEO_WINDOW_POS=512,320 setsid desmume-cli --cpu-mode=1 --num-cores=1 \
  "/workspace/roms/解谜系列Vol.05：数回.nds" >/tmp/desmume_v5.log 2>&1 &
# 窗口须 windowfocus；tap 用单条 xdotool（mousemove+sleep+mousedown+sleep+mouseup），
# OFF=(512,320)，见 /tmp/v5lib.py
```

导航链（本轮实测坐标，局部坐标 = 屏幕 − (512,320)）：
标题 `(128,300)` → 存档选择「新規作成」`(70,248)` → 姓名页「決定」→
光标确认框「はい」`(70,315)` → セーブ中 → 主菜单「スタート」`(128,265)` →

点关卡格出详情预览（未クリア / ベストタイム / 尺寸 6x6 等）→ 再点进题 →
**入門第 1 关带 7 页教程**（右下「進む」`(228,370)` 翻页）。

> 踩坑：不带 `--cpu-mode=1 --num-cores=1` + `windowfocus` 时，鼠标触摸与方向键
> 都不被接收（键盘 A 按钮曾偶然生效一次）。分多条独立 `xdotool` 命令发
> mousemove/mousedown/mouseup 也无效，必须用单条命令带 sleep 配对。
