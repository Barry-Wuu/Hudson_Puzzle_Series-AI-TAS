- `extract_vol3_answers.py`：从 ROM 静态提取，逐关五项自检（题面合法 / 答案合法数独解 / 答案覆盖给定格 / 题面唯一解 / 唯一解与 ROM 答案逐格一致），**300/300 全通过** → `validation/puzzles.json`（178KB，含题面、解、难度、档内编号、空格数）。

## 录制流程（先提取、后录制）

早期版本把「翻教程、放大截图读题、离线求解」都放在**游戏计时器运行期间**，导致 No.001 记录虚高到 `00:08:07` 且「填的时候计时器不是从零开始」。按用户要求改为：

1. 离线跑 `extract_vol3_answers.py` → `puzzles.json` → `答案.md`，**全部 300 关答案提前在手**。
2. 录制脚本从 `puzzles.json` 直接读该关解，进关后只做「按表填入」，不读题、不求解、不截图研究。
3. 进入作答界面时计时器 `00:00:00` 起跳；等「スタート」开场演出消失（约 2.5s）再开填——否则前 1~2 格点击会被演出吞掉。
4. 快点击（合并鼠标事件，每格约 0.1s）+ 逐格漏填自检补漏（`validation/enter_timer_0000.png` 为计时零点证据）。
5. 通关后点「もどる」返回选关页触发「セーブ中」写盘。

干净重录版 `00:00:09` 已**替换**旧版 `00:08:07` 视频：`/workspace/Vol.3_やさしい录播/Vol.3_数独_やさしい_001_通关实况_256x384.mp4`（48s，H.264 256×384 30fps + AAC，mean −18.6 dB；含计时零点→正解定格）。
